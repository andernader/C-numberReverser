# C-numberReverser
A C-code that reverse a two digits number entered by the user.<br>
we have here in this program two method to use in order to reverse the two digit number.<br>
The first one is only to capture the two digits number as a separate variables and showing
them in reverse.<br>
The second method is using the divider and reminder operator, by using this method we are
not limited with only two digits numbers we can flip a more than two digits number easily.<br>
